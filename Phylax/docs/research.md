# Research Workspace

Use [`Research/`](../Research/README.md) for exploratory Python scripts and Jupyter notebooks. Typical work includes investigating a market series, forming a hypothesis, trying indicators or features, plotting with Toga, and checking results before moving stable rules into a strategy.

Record the data source, instrument, interval, requested date range, parameters, and assumptions in each experiment. Keep notebooks reproducible and avoid saving credentials, private datasets, large caches, or bulky generated outputs into source control. Toga can chart candles and trailing indicators; Buroka and Kijun can be used when an experiment needs simulated orders and a formal performance report.

See [Tutorial 5: Research with Toga](../tutorial/05-research-and-toga.md) for a short walkthrough.
